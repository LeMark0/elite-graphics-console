# Elite Graphics Console 1.6.1

Elite-styled scrollbars throughout the app: dark recessed tracks, orange thumbs, triangle end controls, hover/drag feedback and matching horizontal scrolling. Plain scrolling panels and text editor content hosts now share the theme. Horizontal step and page commands use the correct axis.

Validated with 45 core tests and 22 WPF checks, including overflowing content on both axes and triangle-button scrolling. Rendered scrollbars and the settings view were inspected. Game settings and preset values are unchanged by this update.
