# 012 — Restore the description sidebar

Status: Accepted, 2026-09-18. Recorded before implementation.

At the user's request, supersede the layout decision in ADR 011: show descriptions in the persistent right-hand setting inspector and restore the compact Setting / Value table. Remove the third column and lower inspector expander. Keep description search, source information, raw values and revision notes. The star-count feature and all setting behaviour remain unchanged.
